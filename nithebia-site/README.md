# DecoracionesNithebia — sitio web público

Sitio estático responsive en HTML, CSS y JavaScript, personalizado con las fotografías incluidas en `assets/`.

## Ejecutar localmente
1. Descomprime el proyecto.
2. Abre `index.html` en el navegador, o usa Live Server en Visual Studio Code.

## Publicar en GitHub Pages
Sube el contenido de esta carpeta a la rama `main` de tu repositorio y configura **Settings → Pages → Deploy from a branch → main → /(root)**.

## Antes de publicar
- Configura el número de WhatsApp en `app.js`, en la constante `WHATSAPP_NUMBER` (formato internacional, solo números).
- Revisa textos, servicios y fotografías.
- El formulario solo prepara un mensaje de WhatsApp; no guarda solicitudes en una base de datos. Para ello debe conectarse al backend/API.
